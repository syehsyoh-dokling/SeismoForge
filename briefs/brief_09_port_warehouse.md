# Project brief: Port Logistics Warehouse

A three-story port warehouse handling time-critical cargo, on softer harbour
soils than the operator's usual sites. The operator's standard fixed-base
design has always been fine elsewhere; the question is whether it still holds
on this ground, and what to do if it does not.

## Project data

- Building use: warehouse
- Stories above grade: 3
- Seismic floor weight: 450 tonnes per floor
- Story lateral stiffness: 200,000 kN/m
- Story height: 4.2 m

## Site hazard

- Design PGA: 0.24 g
- Predominant site period: 0.9 s
- Strong-motion duration: 23 s
- Moat clearance available: 0.45 m
